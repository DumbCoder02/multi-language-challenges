Title: N-Queens Problem

Problem Description
Place N chess queens on an N x N chessboard so that no two queens attack each other. No two queens may share the same row, column, or diagonal.

Count every distinct way to do this, and print the first arrangement found when rows are filled from top to bottom and columns are tried from left to right.

Input Format
A single integer N.

Output Format
Line 1: Total solutions: <count>
If <count> is greater than 0:
  Line 2: First solution:
  Next N lines: the board, using Q for a queen and . for an empty square.
If N is outside the allowed range, print: Invalid input

Constraints
- 1 <= N <= 12

Sample Input 1
4

Sample Output 1
Total solutions: 2
First solution:
.Q..
...Q
Q...
..Q.

Sample Input 2
6

Sample Output 2
Total solutions: 4
First solution:
.Q....
...Q..
.....Q
Q.....
..Q...
....Q.

Sample Input 3
3

Sample Output 3
Total solutions: 0

Sample Input 4
1

Sample Output 4
Total solutions: 1
First solution:
Q
